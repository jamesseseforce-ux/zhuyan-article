# 编辑模式目录

来源：S01（固定提交见 source-map.md）的29项模式，保留“骨架／触发／保护／动作／复扫”结构；P30–P31来自 S03。已按 S02 处理语义冲突，按 S03 限制强制节奏改写。此处是编辑方法，不是朱雀机制或作者鉴定。

本目录描述需要编辑的写作症状，不鉴定文本作者。先判断语义，再看密度、目标语体和信息变化。每个模式都按「骨架 / 触发 / 保护 / 动作 / 复扫」使用；命中多个相邻模式时只处理一次。

适用优先级：[保真与权限边界](fidelity-and-scope.md)高于任何局部动作。相邻条目命中同一问题时只编辑一次。来源论文标签不作为本包检测性能证据，原始链接与文本保留在研究快照中。

## 1. 内容真实性与具体性

### P01 低信息密度与篇幅膨胀

- 骨架：同一判断换词复述，把一句话摊成多段，解释读者已知的常识。
- 触发：删去句子后只减少篇幅，不减少事实、关系或态度。
- 保护：必要定义、教学分解、风险解释和为不同读者提供的复述。
- 动作：合并重复判断，让事实和动作承担主干。
- 复扫：相邻段是否仍回答同一个问题、得到同一个结论。

### P02 泛化而缺少细节

- 骨架：用「相关领域、广泛影响、某种意义、各类场景」回避人物、时间、动作和条件；用「与……有关、存在联系、参与……」代替原文已明确的角色或关系。
- 触发：抽象词取代了原文已有的具体信息，或整段没有可核对对象。
- 保护：原文确实只给出范围或关系判断时，不补造细节，也不因关系模糊而删除这项判断。统计相关性和未确定的角色保留原有强度。
- 动作：恢复原文已有的人、事、时间、条件和关系。例如「他与乐团有关。他创办并指挥该乐团」可合并为「他创办并指挥该乐团」；只有「他与乐团有关」时，不得补成「他是指挥」。
- 复扫：对象和关系是否可回指原文；有没有把参与改成负责、把相关改成因果。

### P03 无证据拔高

- 骨架：由普通事实跳到里程碑、时代转折、文化意义、系统性升级。
- 触发：评价超出原文事实支持，或只是重复气势。
- 保护：作者明确作出的评价属于原意，不能删；只重写承载方式。
- 动作：事实先行，评价另放；纯空洞升华可删除。
- 复扫：结尾是否又把局部事件推到宏大尺度。

### P04 模糊归因、假共识与范围膨胀

- 骨架：「业内人士 / 研究表明 / 普遍认为」「任何人 / 各种场景 / 从个人到组织」。
- 触发：没有来源，或范围超过原文。
- 保护：真实来源、完整调查范围和必要概括。
- 动作：仅在已有材料允许时具体化来源。缺来源则保留归属与原主张，必要时稿外提示；不擅自收窄范围，不把引述改成裸事实。
- 复扫：所有归因和全称判断能否回指信息账本。

### P05 公式化前景、假平衡与正向缝合

- 骨架：「尽管挑战仍值得期待」「既要 X 又要 Y」「负面事实＋未来可期」。
- 触发：没有真实冲突、条件、行动或态度变化。
- 保护：原文确有权衡、计划或作者态度。
- 动作：写清条件和决策；无信息的乐观结尾删除。
- 复扫：每段和全文结尾是否被统一缝回积极方向。

## 2. 证据、推论与结论强度

### P06 表面分析与假揭示

- 骨架：「看似 X，本质 Y」「表面 X，背后 Y」「这说明 / 体现 / 提醒」。
- 触发：X 与 Y 只是两个抽象评价，没有事实建立层次或推论。
- 保护：两项确为作者判断时必须保留含义。
- 动作：让事实先建立关系，再直接写归因或结论。
- 复扫：是否用「真正、其实、深层」换壳继续制造揭示感。

### P07 推论台阶与连接词链

- 骨架：「这意味着→这说明→进一步→由此可见」。
- 触发：连接词增加，信息和证据没有推进。
- 保护：真实演绎步骤、实验推导和必要论证路标。
- 动作：逐步检查蕴含；合并重复结论，保留真实关系。
- 复扫：每个结论是否比前句新增信息，是否超过证据强度。

### P08 虚构因果、比较与权衡

- 骨架：时间先后写成因果，不同尺度硬比较，无冲突事项写成平衡。
- 触发：关系无法从原文证据推出。
- 保护：作者明确主张仍属于原意，不能静默改正。
- 动作：能等义就保留并列入 `【需作者确认】`；无法自然保义则暂停。
- 复扫：因果词、比较级和转折两端是否都有依据与共同尺度。

## 3. 篇章组织与信息推进

### P09 开头复述任务与声明计划

- 骨架：「基于你的需求」「下面将从三方面」「当我们谈论 X」。
- 触发：正文开始前只复述任务或导演读者。
- 保护：正式摘要、演讲导读、确有导航价值的长文说明。
- 动作：直接进入事实、问题或结论。
- 复扫：删去开场后正文是否完整成立。

### P10 任意分层与大纲模板

- 骨架：硬凑三个层面、首先其次最后、每点「标签：解释」。
- 触发：分类混用尺度、项目可合并，或结构不帮助执行和检索。
- 保护：步骤、参数、责任分工、真实分类和长文导航。
- 动作：按读者任务重组为自然段、步骤或真正的层级。
- 复扫：标题和列表是否各自承担不同职责。

### P11 段落过齐与一段一模板

- 骨架：每段同长度、同首句、同一收束，重复“观点—解释—升华”。
- 触发：段落边界服从外观而非信息职责。
- 保护：规范化报告、平行条款和需要快速比较的文档。
- 动作：按事实、原因、限制、行动等职责合并、拆分或调序。
- 复扫：跨段是否仍复述相同主张，段落顺序是否自然推进。

### P12 收尾复述与统一升华

- 骨架：「总之」复述全文，再展望、号召或价值拔高；每段以「这说明」封口。
- 触发：结尾没有新结论、决定或下一步。
- 保护：正式摘要、结论章节和用户要求的行动项。
- 动作：停在最后一个有信息的事实、判断或行动上。
- 复扫：段尾和全文结尾是否重复前文。

## 4. 简体中文句法与语序

### P13 主干后置与前置修饰过载

- 骨架：「在……背景下 / 基于…… / 通过……」叠加，多层定语后才出现谓语。
- 触发：读者需要回看才能找到谁做了什么。
- 保护：法律、公文、技术定义中承担适用范围的前置条件。
- 动作：先恢复主干，再把时间、条件和范围放到动作附近。
- 复扫：每句能否快速指出行动者、动作和对象。

### P14 翻译式代词、被动与定语链

- 骨架：重复「它 / 该 / 其」、连续被字句、英语式从句全部塞进定语。
- 触发：指代机械或主干难找，而非单次出现。
- 保护：消歧所需专名、责任明确的被动句、稳定术语。
- 动作：语境明确时省主语，拆定语，恢复自然话题顺序。
- 复扫：是否为省字制造新歧义。

### P15 标点承载结构

- 骨架：破折号、分号、冒号或括号反复承担本该由句法表达的关系。
- 触发：标点密度和功能单一，换符号仍保留原机械结构。
- 保护：对话中断、真实停顿、并列层级、术语解释和范围连接。
- 动作：先重写句法，再按功能选择标点。
- 复扫：不得只换标点而不改变信息结构。

## 5. 词汇搭配、抽象密度与语义复现

### P16 词汇与语义复现

- 骨架：相邻句重复同一名词、动词或评价，或换同义词重说结论。
- 触发：重复不承担强调、消歧或跨段重启作用。
- 保护：关键术语、法律全称、刻意复沓和避免歧义的点名。
- 动作：合并句子、省略已知主语或统一稳定称呼。
- 复扫：既检查同字重复，也检查换词复述。

### P17 抽象名词化与弱动词

- 骨架：「进行 / 实现 / 推动 / 构建 / 体现＋抽象名词」，`性 / 化` 连续堆叠。
- 触发：行动者和动作被埋，删去外壳不损信息。
- 保护：学术、公文、法律、技术中的稳定术语和必要名词化。
- 动作：恢复谁做了什么；不要机械拆术语。
- 复扫：段落主干是否仍由抽象名词和空动词承担。

### P18 搭配漂移与心理动作直译

- 骨架：「接住观点、击穿思考、托住情绪」等动作词脱离自然对象。
- 触发：可一对一倒译，且目标语体没有约定搭配。
- 保护：真实动作、行业惯用语、人物声口和品牌语言。
- 动作：换成原文含义内的普通动词，或直接写结果。
- 复扫：不要为了口语化制造另一种生硬搭配。

### P19 限定词和安全垫串联

- 骨架：「可能、或许、通常、相对、一定程度上」连续叠加。
- 触发：多个限定表达同一不确定程度。
- 保护：证据等级、适用范围和风险披露。
- 动作：保留最准确的限定，删除重复安全垫。
- 复扫：不得把不确定性清洗成确定判断。

## 6. 修辞、节奏与表现形式

### P20 对称骨架族

- 骨架：「不是而是、并非只是、不只 / 不仅……也 / 更、而非、与其不如、看似本质、既是也是更是、从 X 到 Y 再到 Z」。字面连词可以消失，但“先压低一项、再抬高另一项”的关系仍属同一骨架。
- 触发：结构抽象、对称、反复出现，或两端没有新关系。单次出现而关系清楚、有用时可保留；不因连词本身强制改写。
- 保护：真实引用、固定定义、事实纠错、范围排除和改变后会歧义的表达。
- 动作：冻结两端含义，在原有关系内调整事实主干、句序或分句。原文没有的因果或条件不得补出，不能只留下较响亮的一端。
- 复扫：检查是否只换连接词仍重复同一结论；含义和阅读已清楚时停止，不追求某类句式零出现。

### P21 三连、机械排比与身份升级

- 骨架：三个形容词、动词、身份或尺度整齐排列，末项继续拔高。
- 触发：项目近义、尺度不同，或只是追求完整感。
- 保护：真实完整清单、步骤、法定要件和有意修辞。
- 动作：合并能落成同一动作层的项目；功能、流程和身份评价属于不同层级时，身份评价另起一句。保留每项断言强度，例如「体现了流程优化」不能加强为「优化了流程」。只换连词而不解决实际重复，不算改善；三项独立且并列有助阅读时保留。
- 复扫：独立项目是否全部保留，合并后是否误把不同层级的命题当成同义重复。

跨句、跨段也要扫描三连：三个平行例子各占一句或一段，随后接一条没有新增信息的结论，仍可能只是凑齐结构。按各例子的实际作用重排、合并重复表达，删除无信息的收束；不得为了打破三连删掉独立例子。例如复盘列出授权遗漏、日志丢失和通知延迟三件故障时，三件都要保留。联动“段落过齐与一段一模板”复扫，不重复处理；真实分类和作者有意排比仍受保护。此项通过 S01 间接继承 Humanizer 的 forced-triads 编辑建议；不是检测分数承诺。

### P22 句长与句式节奏过齐

- 骨架：连续句使用同一空壳、同主语同谓语并重复信息；句子长度接近本身不构成问题。
- 触发：跨句群观察到模板复现并影响理解、推进或作者声音，而非测量句长方差。
- 保护：条款、步骤、诗性排比和有意节奏。
- 动作：为恢复信息推进而合并碎句、拆开过载长句或调整句序；不为制造长短变化改写清楚的句子。
- 复扫：不能靠随机标点或口头语伪造变化。

### P23 预判标签、假口语与礼貌抛光

- 骨架：「显而易见、值得注意、核心逻辑很清晰、说实话、当然、希望有帮助」。
- 触发：标签不增加证据，态度词不属于作者声口或目标体裁。
- 保护：必要风险提示、真实人物口吻、客服礼貌和演讲互动。
- 动作：删除标签，直接呈现内容；不要硬加第一人称。
- 复扫：结论是否仍由标签代替证明。

## 7. 受众、体裁、平台与交互残留

### P24 人称与礼貌模板

- 骨架：「您 / 你可能 / 大家都 / 希望对你有帮助」机械出现。
- 触发：与目标受众和体裁不符，或泛化第二人称替代具体对象。
- 保护：客服、教程、演讲和真实互动。
- 动作：恢复明确对象或省略无用人称。
- 复扫：不要把所有文本强行改成第一人称。

### P25 体裁与平台失配

- 骨架：百科正文带聊天礼貌，报告写成营销稿，教程写成演讲，自媒体机械套平台话术。
- 触发：形式、词汇和互动方式妨碍目标用途。
- 保护：用户指定的平台规范和作者稳定声口。
- 动作：按实际读者任务重建语体、层级和互动方式。
- 复扫：平台特征只在对应平台使用，不推广为通用规则。

### P26 标题、列表、粗体与表格模板

- 骨架：每点「粗体标签：解释」、无必要编号、叙事被拆表。
- 触发：格式只为显得完整，不帮助检索、执行或比较。
- 保护：步骤、参数、责任矩阵、数据对照和长文导航。
- 动作：恢复自然段或真正有功能的结构；不得丢字段。
- 复扫：Markdown 是目标格式时保留，不把源码标记本身视为症状。

### P27 同声引语与伪现场

- 骨架：所有受访者都使用同样完整、正式的句式，旁白替引语解释情绪。
- 触发：只作为核验提醒，中文证据较弱。
- 保护：真实引语正文绝不擅改。
- 动作：检查来源和周边叙述；无法核验时标记，不改引语内容。
- 复扫：不得为了“更像真人”给引语添加停顿、错字或口头语。

## 8. 来源、引用与事实一致性

### P28 模型残留、占位符与虚构链接

- 骨架：知识截止声明、提示词回声、`[姓名] / XX / 待补链接`、虚构 DOI 或网址。
- 触发：单次即可处理，因为它影响可交付性或事实可靠性。
- 保护：教学示例中的变量、真实匿名标记和用户要求保留的模板槽位。
- 动作：保留并要求补充，或删除明确无效的过程残留；绝不代填。
- 复扫：正文、脚注、链接和引用表都要检查。

### P29 引用绑定与来源漂移

- 骨架：调序后引文离开支持对象，来源被写成支持更强结论，多个来源混成一个共识。
- 触发：文内陈述和来源之间不再一一对应。
- 保护：默认不承担外部真伪核验。
- 动作：引用与被支持陈述一起移动；发现支持范围不符时列入稿外核对，获得纠错授权后才调整实质主张。
- 复扫：逐条确认数字、引语、归因和结论的来源绑定。


## 9. 补充信号（S03）

### P30 理想化的代理人格

- 骨架：把工具写成“永不疲倦的管家”“永远耐心的同事”等完美角色，用角色代替实际能力。
- 触发：人格包装遮住原稿已有的功能、行为或限制；不是出现比喻就删。
- 保护：作者明确评价、真实引用、有意比喻及原有能力断言。
- 动作：优先用原稿已有的动作承载功能；无法等义去掉比喻时保留，不新增功能，不把“能做到”改成“已经做到”。
- 复扫：工具到底做了什么仍可说明；没有为去夸张丢掉作者判断或悄悄纠正事实。

### P31 段首评论缺少指向

- 骨架：换段后只剩“这很关键”“这值得警惕”，读者难以知道指哪件事。
- 触发：上下文出现多个可能对象，省略造成理解负担。
- 保护：指向清楚的自然省略和作者有意停顿。
- 动作：恢复原稿已有的具体对象或接回前句；不凭空补原因和结论。
- 复扫：该判断确实对应原对象，与P14的省略主语规则按指代是否清楚分流。

规则来源、上游原路径及合并关系见[source-map.md](source-map.md)。上游包含变更事实的示例未随本目录移植；不能照例句外形重写其他文章。
